# Калькулятор доп. выручки от динамических цен — прототип для лендинга Orbita

Одна HTML-страница (`index.html`) без зависимостей и сборки, только frontend. Откройте файл в браузере.

Посетитель видит пример с тестовыми данными, может поменять товары, цены, процент наценки, продажи за смену, число точек и пиковых смен и нажать «Рассчитать».

## Формулы

Для каждой строки товара (1 точка, 1 смена высокого спроса):

- надбавка, ₽ = стоимость × % / 100
- выручка = стоимость × продажи за смену
- выручка с динамической ценой = (стоимость + надбавка) × продажи за смену
- доп. выручка = выручка с динамической ценой − выручка

Итоги:

- выручка в пиковые смены, с динамическими ценами, доп. выручка — суммы по строкам
- прирост, % = доп. выручка / выручка в пиковые смены × 100
- доп. выручка сети за месяц = доп. выручка смены × количество точек × смен повышенного спроса в месяц
- доп. выручка за год = доп. выручка сети за месяц × 12

## Тестовые данные

| Товар | Стоимость, ₽ | Увеличение, % | Продаж за смену |
|---|---|---|---|
| Лагер | 110 | 8 | 250 |
| Пилснер | 140 | 4 | 140 |
| Пшеничное | 125 | 6 | 210 |

Точек — 10, смен повышенного спроса — 8 в месяц.

Результат: 73 350 ₽ → 77 909 ₽, +4 559 ₽ (+6,2%) за смену; по сети — +364 720 ₽ в месяц, +4 376 640 ₽ в год.
